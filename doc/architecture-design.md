# Architecture Design

## Core Principles
- Secure first by design
- Users own their data; privacy is a must and not negotiable; Users must consent and understand if their data is leaving a boundary they control
- Open source, users can host on their own but a paid hosting model will be available
- Data in paid hosting model must be encrypted by user/customer keys; platform owners can never see the data
- AI can be used to analyze data, detect patterns or trends
- Users will have the ability to use local or hosted models for AI; security and
